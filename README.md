# Clean Code Formatting Assignment – PaymentProcessor

## Overview
This assignment focuses on improving code readability by applying Clean Code (Chapter 5 – Formatting) principles to an existing, working Java class.

The provided `PaymentProcessor` class already followed good design and logic practices.  
The goal of this task was **strictly formatting-related refactoring** — no functional or behavioral changes were made.

---

## Objective
- Apply **horizontal and vertical formatting rules**
- Improve readability and maintainability
- Preserve existing logic and behavior
- Demonstrate understanding of Clean Code formatting standards

---

## Scope of Changes
 **Formatting only**  
 **No logic, behavior, or design changes**

---

## Formatting Improvements Applied

### Horizontal Formatting
- Consistent 4-space indentation
- Proper spacing around operators and commas
- Long lines broken into readable blocks
- One statement per line
- Avoided horizontal alignment columns

### Vertical Formatting
- Applied the **newspaper metaphor**
  - High-level methods appear first
  - Details follow progressively
- Added blank lines between logical sections
- Grouped related methods together
- Ensured caller methods appear before callee methods

### Code Ordering
The class structure follows this strict order:
1. Constants
2. Fields
3. Constructor
4. Public methods
5. Private helper methods
